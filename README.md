## Estrutura dos arquivos
- `index.html`: estrutura e conteúdo do site.
- `css/style.css`: estilos personalizados.
- `imagens/`: pasta reservada para imagens do projeto.

## Recurso adicional
Foi adicionada uma animação nos cards da seção Projetos. Ao posicionar o cursor sobre um card, ele se desloca levemente para cima e recebe uma sombra mais evidente. O efeito foi implementado no arquivo `css/style.css` com as propriedades `transition`, `transform` e `box-shadow`, utilizando o seletor `:hover`.
